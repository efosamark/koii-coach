CHAPTER 09 / ABOUT 90–150 MINUTES

Thodorakis house / five-sample track

Make a complete 112-bar, four-bar house track at 128 BPM using only five loaded samples: C4 kick, C5 clap/snare, C3 closed hat, C7 open hat/texture and C2 bass or tonal stab. This is an exact working recipe—not a promise of a mastered release.

Important: Use a disposable, empty project. Stop playback before every position-by-position edit. This recipe assumes 16 timing, not 1 or 16T. Wrong sequenced note? Navigate to its position, then use a brief ERASE + its pad. Never use ERASE + SOUND for a wrong sequenced hit: that deletes the audio sample.

Your destination

Tempo
128 BPM
Main loop
4 bars / 64 steps
Roles
A drums · B bass/stab · C texture · D transition
Song
28 song positions / 112 bars / about 3:30

C4 and C2 carry the dancefloor. C3 and C7 create movement. C5 marks the backbeat. Do not add more sounds until these five roles are clear.

0 / 48 steps checked

01 / Protect your music and set 128 BPM
  1. Choose a disposable project. Press MAIN. If PLAY is lit or music runs, press PLAY once to stop it.
  2. Press TEMPO. Turn X until the display shows 128. Press MAIN again.
  3. Press TIMING. Turn X until the display shows 16: not 1 and not 16T. Leave swing neutral for the first version. Press MAIN.
  4. Select groups A, B, C and D and confirm each has an empty one-bar pattern. If a group contains music you want to keep, choose another empty project or pattern.
02 / Assign your five samples
  1. Press SOUND and select pad A1. Choose or confirm C4 as your kick. It should be short and punchy, not a long booming sound.
  2. Select A2 and assign C5 as clap or snare. Select A3 and assign C3 as closed hat.
  3. Select A4 and assign C7 as open hat, ride, shaker or atmospheric texture. Lower its level with X if it is bright or long.
  4. Select B1 and assign C2 as bass, bass stab, chord stab or tonal percussion. Keep it quieter than the kick for now.
03 / Write the four-on-the-floor foundation
  1. Press MAIN, select group A, and stop playback. Go to 1.1.1. Hold RECORD, tap A1 (C4), release.
  2. Write A1 at 1.2.1, 1.3.1 and 1.4.1. These four kicks are the house foundation.
  3. At 1.2.1, hold RECORD and tap A2 (C5). Repeat at 1.4.1. The clap/snare sits on beats 2 and 4.
  4. Write A3 (C3) at 1.1.3, 1.2.3, 1.3.3 and 1.4.3. Play one loop, then stop. The hats should feel smaller than the kick and clap.
04 / Make the drums move across four bars
  1. With A selected and stopped, tap RECORD to arm. Hold SHIFT and press plus once to double the one-bar pattern to two bars. Repeat once more to make four bars. Disarm RECORD.
  2. Add A3 closed-hat accents at 2.2.4 and 4.2.4. These tiny extra ticks stop the groove feeling mechanical.
  3. Write A4 (C7) at 2.4.3 and 4.4.3. At both positions, briefly erase A3 so the open texture replaces the closed hat rather than stacking with it.
  4. Play the four-bar drum loop. Bar 4 should make you expect bar 1 again. If it feels too busy, remove one extra C3 hit—not the kick or clap.
05 / Build the C2 bass or stab phrase
  1. Select B. Stop playback. Arm RECORD and press plus until B is four bars long. This creates room; it does not write notes.
  2. Write B1 (C2) at 1.1.3, 1.2.2, 1.3.3 and 1.4.2. These notes land after the kick, not directly on top of it.
  3. Write B1 at 2.1.3, 2.2.3, 2.3.2 and 2.4.3. Repeat the same idea in bar 3: 3.1.3, 3.2.2, 3.3.3 and 3.4.2.
  4. Write B1 at 4.1.3, 4.2.3 and 4.3.2. Leave 4.4.3 empty for now. Play A and B together.
06 / Make kick and C2 breathe
  1. Listen to only A and B for at least four full loops. The kick must remain clear on every beat; C2 should feel bouncy rather than constant.
  2. If kick and C2 become muddy, stop. In SOUND, lower B1’s X level or shorten its tail with Y. Change only one thing, then listen again.
  3. If your installed OS has sidechain: press SHIFT + FX, use plus to reach sidechain, set A1 as source and B as destination. Use a short X length and moderate Y shape. Skip this if it is not available.
  4. Press SHIFT + MAIN once to commit this four-bar core into a new scene. Write the scene number as DROP A.
07 / Turn C7 into a hook or atmosphere
  1. Select C. Stop playback. Arm RECORD and press plus until C is four bars.
  2. Write C1 (C7) at 1.1.1 only. This gives the loop one clear moment of lift or atmosphere per four bars.
  3. Add C1 at 3.3.4 as a small answer. If C7 is long or noisy, lower its X level before adding more.
  4. Play all groups. C7 should add air, not bury the kick, clap or C2. Press SHIFT + MAIN and save this version as DROP B.
08 / Create real section differences
  1. Select DROP A. Press SHIFT + MAIN to copy it as INTRO. In INTRO erase all B1 C2 notes and all C1 C7 notes. Keep only C4, C5 and C3.
  2. Select DROP A again. Commit a copy as GROOVE. Erase C1 from this copy, leaving drums plus C2.
  3. Select DROP B. Commit a copy as BREAK. Erase every A1 kick and every B1 C2 note. Keep C3, C5 and C7. If it feels too empty, keep one quiet C3 hit.
  4. Select BREAK. Commit a copy as BUILD. Put A1 kick back only at 1.1.1, 1.2.1, 1.3.1 and 1.4.1. Add A2 claps at 4.3.1, 4.3.3 and 4.4.3.
09 / Add a final drop and ending
  1. Select DROP B. Commit another copy as PEAK. In PEAK, erase A1 only at 4.4.1. This tiny gap gives the loop a breath before it repeats.
  2. Optional D group: make D four bars and put a short impact, reverse sound or extra C7 hit on D1 at 1.1.1. Use it only in BUILD and PEAK.
  3. For OUTRO, select GROOVE and commit a copy. Erase C1 and remove extra A3/A4 movement. Keep drums plus C2 simple.
  4. Listen from INTRO into GROOVE, then DROP A and DROP B. New elements should arrive in this order: drums, C2, then C7 atmosphere.
10 / Build the 112-bar song list
  1. Every scene in this recipe must have a longest pattern of exactly four bars. Check groups A, B, C and D in each scene before arranging.
  2. On OS 2.0 or later, hold MAIN then press ENTER to open the Song list. Start only in an unused song list.
  3. Assign positions 1–2 INTRO; 3–4 GROOVE; 5–8 DROP A; 9–12 DROP B; 13–14 BREAK; 15–16 BUILD; 17–20 DROP A; 21–24 DROP B; 25–26 PEAK; 27–28 OUTRO.
  4. Select Song position 1 and press SHIFT + PLAY. At 128 BPM this is 112 bars, about 3 minutes 30 seconds.
11 / Five-sample mix check
  1. Play the entire arrangement without touching controls. Write down only three things you dislike.
  2. Set C4 kick as the loudest drum. Keep C5 slightly below it, C3 lower still, and C7 subtle.
  3. Keep C2 below the kick in level. If the low end is muddy, shorten C2’s tail before lowering everything.
  4. Test at low volume and on the speaker you will actually use. If it feels crowded, remove one C3 or C7 event rather than adding another sound.
12 / Save, record and play it
  1. Listen especially to DROP B → BREAK → BUILD → DROP A. The breakdown should create anticipation; the return should feel bigger without everything becoming louder.
  2. Record one full pass before experimenting again. COMMIT is a scene copy, not an audio export.
  3. Write down the project number plus INTRO, GROOVE, DROP A, DROP B, BREAK, BUILD, PEAK and OUTRO scene numbers.
  4. You are done when the track plays from start to finish, C4 and C2 stay clear, C7 appears only where it matters, and the drops feel different.
