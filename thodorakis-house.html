CHAPTER 09 / ABOUT 90–150 MINUTES

Thodorakis voice house

Make a 128 BPM house track with a normal K.O. II drum kit, then use your five Thodorakis voice samples—C4, C5, C3, C7 and C2—as the vocal identity: hook, chopped phrases, answering stabs and atmosphere. The voice is the instrument; it is not the kick, snare or hat.

Important: Use a disposable project. Stop playback before editing note positions. This recipe assumes 16 timing. To remove one wrong sequenced note, navigate to it and briefly press ERASE + that pad. Never use ERASE + SOUND to remove a sequenced note: that deletes the audio sample.

Sound roles

Group A — drums
Normal kick, clap/snare, closed hat, open hat
B1 — main voice
C4: strongest vocal phrase or hook
B2 — answer voice
C5: short vocal answer or word
C1 — chop
C3: tiny syllable, breath or rhythmic vocal stab
C2 — texture
C7: longer atmospheric vocal texture
C3 — second hook
C2: alternative phrase for variation

Keep the drums simple and repetitive. Let the Thodorakis voice arrive, disappear, and return—this is what makes the track feel vocal rather than busy.

0 / 48 steps checked

01 / Protect your music and set 128 BPM
  1. Choose a disposable project. Press MAIN. If PLAY is lit or music runs, press PLAY once to stop it.
  2. Press TEMPO. Turn X until the display shows 128. Press MAIN again.
  3. Press TIMING. Turn X until the display shows 16: not 1 and not 16T. Leave swing neutral for the first version. Press MAIN.
  4. Check that groups A, B and C contain empty one-bar patterns. If they contain music you want to keep, choose another empty project.
02 / Build a normal house drum kit
  1. Press SOUND and select A1. Choose a normal short punchy kick—not a Thodorakis voice sample.
  2. Select A2 and choose a normal clap or snare. Select A3 and choose a normal closed hat.
  3. Select A4 and choose a normal open hat, ride or shaker. Keep it quieter than the kick and clap.
  4. Play each drum pad once. You should immediately recognise them as drums; none of them should be a voice sample.
03 / Write the four-on-the-floor drums
  1. Press MAIN, select A, and stop playback. Go to 1.1.1. Hold RECORD, tap A1, release.
  2. Write A1 at 1.2.1, 1.3.1 and 1.4.1. These four kicks are the house foundation.
  3. Write A2 at 1.2.1 and 1.4.1. The clap/snare marks beats 2 and 4.
  4. Write A3 at 1.1.3, 1.2.3, 1.3.3 and 1.4.3. Play one loop, then stop.
04 / Make the drums four bars long
  1. With A selected and stopped, tap RECORD to arm. Hold SHIFT and press plus once to double the one-bar pattern to two bars.
  2. Repeat SHIFT + plus once more to make the drum pattern four bars long. Disarm RECORD.
  3. Add A3 closed-hat accents at 2.2.4 and 4.2.4.
  4. Write A4 at 2.4.3 and 4.4.3. At both positions, briefly erase A3 so the open hat replaces the closed hat.
05 / Prepare the Thodorakis voice samples
  1. Press SOUND and select B1. Assign C4, your strongest Thodorakis vocal phrase. Trim silent space at the start with X and shorten the tail with Y if needed.
  2. Select B2 and assign C5. Choose a short word, syllable or vocal answer—not a long phrase.
  3. Select C1 and assign C3. Choose a very short vocal chop, breath or syllable.
  4. Select C2 and assign C7 as a longer atmospheric vocal texture. Select C3 and assign C2 as a second vocal phrase for variation.
06 / Set voice levels before arranging
  1. In SOUND, set B1 (C4) clearly audible but below the kick and clap in level.
  2. Set B2 (C5) quieter than B1. It should answer the main phrase, not compete with it.
  3. Set C1 (C3) low: it is a rhythmic detail, not a lead vocal.
  4. Set C2 (C7) low enough that it creates air without making the words unclear. Keep C3 (C2) reserved for a later section.
07 / Place the main vocal hook
  1. Select B. Stop playback. Arm RECORD and press plus until B is four bars long.
  2. Write B1 (C4) at 1.1.1. This is the main Thodorakis vocal hook.
  3. Write B2 (C5) at 3.2.3 as a short answer. If it clashes with the main phrase, move it to 3.3.3 or remove it.
  4. Play A and B. The drums should groove steadily while the voice feels like the feature.
08 / Add vocal chops and atmosphere
  1. Select C. Stop playback. Arm RECORD and press plus until C is four bars long.
  2. Write C1 (C3) at 2.4.4 and 4.2.4. These tiny chops should add rhythm, not fill every gap.
  3. Write C2 (C7) at 1.1.1 only. This gives the loop one atmospheric vocal moment per four bars.
  4. Play all groups. If the vocals feel crowded, remove C1 first; do not lower the kick or remove the main hook.
09 / Save the main drop
  1. Listen to A, B and C together for several loops. The kick must stay clear, the voice hook must be recognisable, and the chops must not bury the words.
  2. If C4 and C7 overlap badly, move C7 to 3.1.1 or shorten its tail with Y.
  3. If the vocal feels too dry, use FX on group C with a small reverb send. Keep group A’s FX send low.
  4. Press SHIFT + MAIN once to commit this four-bar version as DROP A. Write down its scene number.
10 / Create intro, groove and variation
  1. Select DROP A and press SHIFT + MAIN to copy it as INTRO. In INTRO, erase B1, B2, C1 and C2. Keep only the normal drum kit.
  2. Select DROP A again and commit a copy as GROOVE. In GROOVE, erase C1 and C2, leaving drums plus the main C4 vocal hook.
  3. Select DROP A once more and commit a copy as DROP B. In DROP B, add C3 (C2) at 2.1.1 as a second vocal phrase.
  4. Play INTRO → GROOVE → DROP A → DROP B. Each section should add vocal information without becoming constantly busy.
11 / Build breakdown and final drop
  1. Select DROP B and commit a copy as BREAK. Erase A1 kick, A2 clap and B1 main hook. Keep A3, a little A4, and C2 (C7).
  2. Select BREAK and commit a copy as BUILD. Return A1 kick at 1.1.1, 1.2.1, 1.3.1 and 1.4.1. Add A2 claps at 4.3.1, 4.3.3 and 4.4.3.
  3. Select DROP B and commit a copy as PEAK. In PEAK, erase A1 only at 4.4.1 for a small breath before the loop returns.
  4. For OUTRO, copy GROOVE and remove C1/C2 and extra A4 hits. Keep drums plus the C4 hook simple.
12 / Arrange, mix and record
  1. Open the Song list with MAIN + ENTER on OS 2.0 or later. Use an unused song list.
  2. Assign: 1–2 INTRO; 3–4 GROOVE; 5–8 DROP A; 9–12 DROP B; 13–14 BREAK; 15–16 BUILD; 17–20 DROP A; 21–24 DROP B; 25–26 PEAK; 27–28 OUTRO.
  3. Play the full arrangement. The Thodorakis voice should be the memorable element; drums should support it, not overwhelm it.
  4. Record one full pass before changing more. COMMIT copies a scene; it does not export audio.

Voice-first rules

ProblemFix
Voice sounds like percussionUse longer phrases, lower level, and place them off the kick
Words are unclearReduce C3/C7, shorten tails, or add only a little reverb
Track feels emptyBring back C4 or add one C2 phrase—not more drums
Track feels crowdedRemove a C3 chop or C7 texture
Hook loses impactKeep it out of INTRO and BREAK; return it at the drop
