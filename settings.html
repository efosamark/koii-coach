Your K.O. II’s OS version

This course is written for OS 2.5.x, the latest release. Choose the version on your K.O. II: steps that need a newer OS than the one you choose show a “Needs OS …+” badge. The browser cannot detect or update it.

While practising

Keep the screen on while practising

Auto keeps the screen awake while you work through the steps, so a propped-up phone stays readable between presses. Off leaves it to your device’s own screen timeout.

Your progress

Progress stays in this browser.

Progress stays in this browser, without cloud sync. Clearing browser data, or some phones’ storage clean-up, can remove it. Save a progress file now and then; it covers every chapter.

Offline and version

Offline use needs one complete visit to the online site first; external guides still need internet.
